# Installation d'InfraLab (procédure fictive)

> Document pédagogique : aucune de ces étapes n'installe quoi que ce soit.

## Prérequis

- Un terminal Bash (Linux, ou Git Bash sous Windows)
- Git

## Étapes

1. Récupérer le dépôt : `git clone <url> infralab`
2. Copier le fichier d'exemple : `cp config/application.env.example config/application.env`
3. Lancer la vérification : `bash scripts/healthcheck.sh`
